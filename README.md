# Поиск ниш iOS-приложений (App Store США)

Каждый день GitHub Actions собирает данные из App Store США, считает прирост оценок
и ориентировочную выручку и публикует таблицу на GitHub Pages.

- `collector.py` — сборщик (менять не нужно)
- `config.yaml` — настройки (пороги кандидатов, время работы, модель выручки)
- `keywords.txt` — поисковые запросы, можно дописывать свои
- `known_revenue.csv` — реальная выручка приложений из открытых источников; по ней инструмент проверяет свою точность и подправляет оценки (обновлять раз в квартал)
- `site/` — сайт с таблицей
- `.github/workflows/daily.yml` — расписание запуска

База хранится в ветке `data` (перезаписывается каждый день, поэтому репозиторий не разрастается).

Ручной запуск: вкладка **Actions** → **Сбор данных** → **Run workflow**.
Скачать отчёт без сайта: открыть любой запуск в Actions → внизу **Artifacts** → `report`,
распаковать и открыть `index.html`.

Все оценки выручки ориентировочные: это модель, а не данные Apple.
